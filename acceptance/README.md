# 离线验收说明

`samples` 目录中的文档全部为虚构材料，不含客户数据，可用于验证导入、分类、正文搜索、预览、复制和引用功能。

## 建议验收步骤

1. 安装 ARM64 `.deb` 后启动文澜资料库，选择一个空目录建立资料库。
2. 导入 `samples` 文件夹，确认共导入 4 份文档，原文件仍然保留。
3. 新建“人事制度”“财务制度”“项目资料”三个分类并分别分配文档。
4. 搜索“年度继续教育”，应命中《员工培训管理制度》。
5. 搜索“有效票据”，应命中《差旅费用报销办法》。
6. 搜索“诊断日志”，应命中《资料管理项目会议纪要》。
7. 在程序内预览正文，分别测试复制内容和带来源引用。
8. 使用 WPS 打开任一文档，修改并保存，返回程序后确认正文与索引可更新。
9. 将一份文档移入回收站并恢复，确认文档可重新搜索。
10. 点击“导出诊断包”，确认生成 ZIP 文件，再把该文件反馈给开发方。

## 客户反馈内容

- 银河麒麟版本、glibc 版本和架构检测结果。
- 安装是否成功，程序是否能够从桌面菜单启动。
- 上述步骤的通过或失败序号。
- 程序生成的脱敏诊断 ZIP。

不要发送真实业务文档、资料库目录、截图中的文件名或正文。
